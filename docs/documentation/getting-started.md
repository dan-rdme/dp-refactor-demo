# 📝 Getting Started

Getting started with our API is as easy as teaching a dog to sit! Here's how:

1. **Register for API Access**: Sign up for a free account to receive your API key. This key will authenticate all your requests to our services.

2. **Install the SDK**: We offer SDKs in various languages to make integration a walk in the park. Here's how to install our Python SDK:

```python
pip install pawsitively-perfect-api
```

3. **Make your first API call**: Here's a simple example of scheduling a grooming appointment:

```python
import pawsitively_perfect as pp

pp.api_key = "YOUR_API_KEY"

appointment = pp.appointments.create(
    pet_id="goodboy123",
    service_type="full_groom",
    date="2024-01-15",
    time="10:00"
)

print(appointment)
```
